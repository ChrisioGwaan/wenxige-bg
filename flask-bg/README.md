# Flask Backend (Lightweight) - Flask 后端轻量版

A lightweight Flask backend for a web application.

### Installation - 安装环境

1. Create Virtual Environment (Only need to execute once. If venv folder exists, skip this step) - 创建虚拟环境（只需要执行一次，如果存在venv文件夹，则跳过此步骤）

```bash
python -m venv venv
```

2. Activate Virtual Environment - 激活虚拟环境

```bash
# On Linux or macOS
source venv/bin/activate  

# On Windows use
venv\Scripts\activate
```

3. Install Dependencies - 安装依赖

```bash
pip install -r requirements.txt
```

4. If you need to update the dependencies, run the following command - 如果需要更新依赖，请运行以下命令

```
pip freeze > requirements.txt
```
